DEV LAUNCH:

1. Open VS Code (or other IDE)
2. Initialize git: ```git init```
3. Clone the repo: ```git clone https://github.com/K1llaro/revISE.git```
4. Open the revISE folder with your VS Code (or other IDE)
5. Launch an application using: ```npm run dev```
6. Open the locally hosted websit on your device with this link: ```http://localhost:4321/#```
