# revISE

Interactive study and revision station for University of Limerick Immersive Software Engineering (ISE) students. It generates dynamic quizzes, programming exercises, and mental code-tracing drills based on the UL curriculum, features local AI key storage, and connects to a unified educational data layer.

## Development

```sh
npm run dev
```

Starts the local development server at `http://localhost:3000`.

## Build

```sh
npm run build
npm run start
```
